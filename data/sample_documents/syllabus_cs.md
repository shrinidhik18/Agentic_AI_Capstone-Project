# Computer Science and Engineering (CSE) - Regulations & Syllabus

**Institute:** NMAM Institute of Technology, Nitte (Deemed to be University)  
**Degree:** Bachelor of Technology (B.Tech.) in Computer Science & Engineering  
**Scheme:** Choice Based Credit System (CBCS)  
**Total Credit Requirement:** 160 Credits  

## 1. Scheme of Teaching and Examination

### Semester I & II (First Year Engineering - CS Cycle)
- **26MAT103 / 25MAT001**: Calculus and Linear Algebra (BSC) - 4 Credits (3-1-0)
- **PH1004-1 / 26PHY102**: Quantum Computing and Modern Physics (BSC) - 4 Credits (3-0-2)
- **CY1003-1 / 26CHY104**: Materials Chemistry for Computer Systems (BSC) - 4 Credits (3-0-2)
- **CS1001-2 / 26CSE102**: Problem Solving through Programming in C (ESC) - 4 Credits (3-0-2)
- **CS1005-2 / 26CSE103**: Introduction to Python Programming (ESC) - 3 Credits (2-0-2)
- **EE1001-2 / 26EEE102**: Basic Electrical Engineering (ESC) - 3 Credits (2-0-2)
- **EC1001-1 / 26ECE101**: Basic Electronics & Embedded Systems (ESC) - 3 Credits (3-0-0)
- **EC1002-2 / 26ECE111**: Applied Digital Logic Design (ESC) - 3 Credits (2-0-2)
- **ME1004-1 / 26MEC122**: Engineering Visualization (ESC) - 2 Credits (0-0-4)
- **HU1001-1 / 26HSS101**: Technical English (AEC) - 2 Credits (1-0-2)
- **HU1002-1 / 26HSS102**: Constitution of India & Professional Ethics (HSMC) - 1 Credit (1-0-0)
- **CV1005-1 / 26CIV104**: Environmental Studies & Sustainability (HSMC) - 1 Credit (1-0-0)

### Semester III (CSE)
- **25MAT204**: Discrete Mathematical Structures (BSC) - 4 Credits (3-1-0)
- **25CSE201**: Data Structures (PCC) - 4 Credits (3-0-2)
  - *Modules:* Stacks, Queues, Linked Lists, Binary Trees, AVL Trees, Heaps, Graph Algorithms, Hashing Techniques.
- **25CSE202**: Object Oriented Programming with Java (PCC) - 4 Credits (3-0-2)
  - *Modules:* Classes & Objects, Inheritance, Interfaces, Exception Handling, Multithreading, Generics, Stream API.
- **25CSE211**: Computer Architecture and Organization (PCC) - 3 Credits (3-0-0)
  - *Modules:* Machine Instructions, Addressing Modes, ALU Design, Pipelining, Memory Hierarchy, Cache Mapping, I/O Interfacing.
- **HU1010-1**: Research Methodology & IPR (HSMC) - 2 Credits (2-0-0)
- **25CSE203**: Data Structures Lab (PCC-Lab) - 1.5 Credits (0-0-3)

### Semester IV (CSE)
- **25MAT003**: Probability, Statistics and Queuing Theory (BSC) - 4 Credits (3-1-0)
- **25CSE204**: Design and Analysis of Algorithms (PCC) - 4 Credits (3-0-2)
  - *Modules:* Asymptotic Notations, Divide & Conquer, Greedy Method, Dynamic Programming, Graph Traversal (DFS/BFS), NP-Completeness.
- **25CSE205**: Database Management Systems (PCC) - 4 Credits (3-0-2)
  - *Modules:* ER Modeling, Relational Algebra, SQL Queries, Normalization (1NF to BCNF), Transaction Processing, Concurrency Control (2PL), Indexing (B+ Trees).
- **25CSE206**: Operating Systems (PCC) - 3 Credits (3-0-0)
  - *Modules:* Process Management, Threads, CPU Scheduling, Synchronization (Semaphores, Monitors), Deadlocks, Memory Management (Paging, Virtual Memory).
- **25CSE207**: Microprocessors and Microcontrollers (PCC) - 3 Credits (3-0-0)

### Semester V (CSE)
- **CS3001**: Computer Networks (PCC) - 4 Credits (3-0-2)
  - *Modules:* OSI & TCP/IP Reference Models, Data Link Control (Framing, Flow Control), Network Layer (IP Addressing, CIDR, Routing Algorithms), Transport Layer (TCP, UDP), Application Layer (DNS, HTTP, DHCP).
- **CS3002**: Theory of Computation & Automata (PCC) - 3 Credits (3-0-0)
  - *Modules:* Finite Automata (DFA, NFA), Regular Expressions, Context-Free Grammars, Pushdown Automata, Turing Machines, Decidability.
- **CS3003**: Software Engineering & DevOps (PCC) - 3 Credits (3-0-0)
- **CS31xx**: Professional Elective I (PEC) - 3 Credits
  - Options: Cloud Computing, Web Technologies, Data Mining.
- **CS32xx**: Open Elective I (OEC) - 3 Credits

### Semester VI (CSE)
- **CS3004**: Compiler Design (PCC) - 4 Credits (3-0-2)
  - *Modules:* Lexical Analysis, Parsing (LL, LR), Intermediate Code Generation, Syntax-Directed Translation, Code Optimization, Register Allocation.
- **CS3005**: Machine Learning & AI Foundations (PCC) - 4 Credits (3-0-2)
- **CS31xx**: Professional Elective II (PEC) - 3 Credits
- **CS31xx**: Professional Elective III (PEC) - 3 Credits
- **CS3301**: Mini Project / Capstone Design I - 2 Credits

### Semester VII (CSE)
- **CS4001**: Distributed Systems and Big Data (PCC) - 3 Credits (3-0-0)
- **CS41xx**: Professional Elective IV (PEC) - 3 Credits
- **CS41xx**: Professional Elective V (PEC) - 3 Credits
- **CS42xx**: Open Elective II (OEC) - 3 Credits
- **CS4301**: Major Project Phase I - 4 Credits

### Semester VIII (CSE)
- **CS4302**: Major Project Phase II & Dissertation - 8 Credits
- **CS4303**: Internship / Industrial Training - 4 Credits

---
## 2. Examination & Evaluation Pattern
- **CIE (Continuous Internal Evaluation):** 60 Marks (3 MSE Tests + Quiz/Assignment + Lab Evaluation)
- **SEE (Semester End Examination):** 40 Marks (Minimum 35% required in SEE to pass)
- **Attendance Mandate:** Minimum 85% attendance required in all subjects (Detention with N-grade if <75%).
