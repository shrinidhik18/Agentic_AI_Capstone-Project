# Information Science and Engineering (ISE) - Regulations & Syllabus

**Institute:** NMAM Institute of Technology, Nitte (Deemed to be University)  
**Degree:** Bachelor of Technology (B.Tech.) in Information Science & Engineering  
**Scheme:** Choice Based Credit System (CBCS)  
**Total Credit Requirement:** 160 Credits  

## 1. Branch Overview
The Information Science & Engineering program focuses on information processing, data analytics, software development, cloud infrastructure, network engineering, and cybersecurity.

## 2. Semester Schemes

### Semester III (ISE)
- **25MAT204**: Discrete Mathematical Structures (BSC) - 4 Credits (3-1-0)
- **IS3001-1**: Data Communication and Networking (PCC) - 4 Credits (3-0-2)
  - *Modules:* Physical Layer Signals, Data Link Protocols, Routing Algorithms, IP Addressing (IPv4/IPv6), Transport Protocols (TCP/UDP), Socket Programming.
- **IS3002-1**: Ethical Hacking and Network Defense (PCC) - 3 Credits (3-0-0)
  - *Modules:* Footprinting, Scanning Networks, Enumeration, Vulnerability Analysis, System Hacking, Malware Threats, Sniffing, Social Engineering, Cryptography.
- **IS2002-1**: Machine Learning Foundations (PCC) - 3 Credits (3-0-0)
  - *Modules:* Supervised Learning (Regression, Classification), Decision Trees, SVM, Naive Bayes, Unsupervised Learning (K-Means, PCA), Model Evaluation Metrics.
- **IS1602-1**: Unix Shell and System Programming (PCC-Lab) - 2 Credits (0-0-4)
  - *Practical Exam:* 3-hour practical examination on Unix system calls, shell scripts, process creation (fork/exec), inter-process communication (pipes/FIFOs).
- **HU1010-1**: Research Methodology (HSMC) - 2 Credits (2-0-0)
- **MG1002-1**: Financial Management (HSMC) - 2 Credits (2-0-0)

### Semester IV (ISE)
- **25MAT003**: Probability, Applied Statistics and Queuing Theory (BSC) - 4 Credits (3-1-0)
- **IS2503-1**: Software Engineering Practices (PCC) - 3 Credits (3-0-0)
- **IS2504-1**: Web Technologies (PCC) - 4 Credits (3-0-2)
  - *Modules:* HTML5, CSS3, JavaScript ES6+, DOM Manipulation, React.js Frontend, Node.js & Express.js Backend, REST APIs, MongoDB Database Integration.
- **IS3101-1**: Operating Systems Fundamentals (PCC) - 3 Credits (3-0-0)
- **IS2302-1**: User Interface Design (PEC) - 3 Credits (3-0-0)

### Semester V (ISE)
- **IS2201-1**: Information Storage Management (PCC) - 3 Credits (3-0-0)
  - *Modules:* Storage Architecture, RAID Levels, SAN & NAS Systems, Cloud Storage, Data Protection, Backup & Disaster Recovery.
- **IS2212-1**: Business Intelligence and Its Applications (PCC) - 3 Credits (3-0-0)
- **IS3233-1**: Fundamentals of Digital Image Processing (PEC) - 3 Credits (3-0-0)
- **IS3241-1**: Cloud Computing (PEC) - 3 Credits (3-0-0)
  - *Modules:* Virtualization, IaaS, PaaS, SaaS, AWS & Azure Infrastructure, Cloud Security, Serverless Architecture.
- **IS3242-1**: Graphics and Animation (PEC) - 3 Credits (3-0-0)

### Semester VI (ISE)
- **IS2213-1**: Object Oriented Modelling and Design (PCC) - 3 Credits (3-0-0)
  - *Modules:* UML Diagrams (Use Case, Class, Sequence, State Machine), Design Patterns (Creational, Structural, Behavioral), Architecture Tradeoffs.
- **IS3343-1**: Operation Research (PEC) - 3 Credits (3-0-0)
- **IS4224-1**: Software Defined Networks (PEC) - 3 Credits (3-0-0)
- **IS3601**: ISE Mini Project - 2 Credits

### Semester VII (ISE)
- **IS4321-1**: Intrusion Detection System (PEC) - 3 Credits (3-0-0)
  - *Modules:* Anomaly Detection, Signature Matching, Snort IDS/IPS, Network Traffic Analysis, Deep Packet Inspection.
- **IS4323-1**: Wireless Sensor Networks (PEC) - 3 Credits (3-0-0)
- **IS1201-1**: Total Quality Management for Sustainable Growth (OEC) - 3 Credits (3-0-0)
- **IS4701**: Major Project Phase I - 4 Credits

### Semester VIII (ISE)
- **IS4801**: Major Project Phase II & Dissertation - 8 Credits
- **IS4802**: Industry Internship - 4 Credits
