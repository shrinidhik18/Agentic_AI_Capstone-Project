# Computer Science and Engineering (Cyber Security) - Regulations & Syllabus

**Institute:** NMAM Institute of Technology, Nitte (Deemed to be University)  
**Degree:** Bachelor of Technology (B.Tech.) in Computer Science & Engineering (Cyber Security)  
**Branch Code:** CSE-CY / CY  
**Scheme:** Choice Based Credit System (CBCS)  
**Total Credit Requirement:** 160 Credits  

## 1. Branch Overview
The CSE (Cyber Security) program prepares students in cryptography, network defense, ethical hacking, digital forensics, cloud security, application security, and information security management.

## 2. Semester Scheme of Study

### Semester III (CSE Cyber Security)
- **25MAT204**: Discrete Mathematics & Number Theory (BSC) - 4 Credits (3-1-0)
  - Modular Arithmetic, Prime Number Theory, Fermat's & Euler's Theorems, Group Theory, Chinese Remainder Theorem.
- **IS1101-1**: Fundamentals of Cyber Security & Threat Landscape (PCC) - 3 Credits (3-0-0)
  - CIA Triad, Threat Actors, Attack Vectors, Malware Analysis, Security Policies, Risk Management Standards (ISO 27001, NIST).
- **25CSE201**: Data Structures (PCC) - 4 Credits (3-0-2)
- **25CSE202**: Object Oriented Programming (PCC) - 4 Credits (3-0-2)
- **IS1602-1**: Unix Shell & System Security Lab (PCC-Lab) - 2 Credits (0-0-4)

### Semester IV (CSE Cyber Security)
- **CY2001**: Applied Cryptography & PKI (PCC) - 4 Credits (3-0-2)
  - Symmetric Encryption (DES, AES), Asymmetric Encryption (RSA, ECC), Hash Functions (SHA-256, SHA-3), Digital Signatures, Public Key Infrastructure (PKI), TLS/SSL Protocols.
- **CS2006**: Operating System Security (PCC) - 3 Credits (3-0-0)
  - Linux/Windows Kernel Security, Access Control Lists (ACLs), Mandatory Access Control (SELinux), Memory Protection (DEP, ASLR), Buffer Overflow Prevention.
- **25CSE204**: Design and Analysis of Algorithms (PCC) - 4 Credits (3-0-2)
- **25CSE205**: Database Management Systems & Security (PCC) - 4 Credits (3-0-2)

### Semester V (CSE Cyber Security)
- **CY3001**: Network Security & Intrusion Prevention (PCC) - 4 Credits (3-0-2)
  - Firewalls, Packet Filters, Stateful Inspection, Next-Gen Firewalls (NGFW), IDS/IPS Deployment, VPN Protocols (IPsec, OpenVPN), Wireless Security (WPA3).
- **CY3002**: Ethical Hacking & Penetration Testing (PCC) - 4 Credits (3-0-2)
  - Reconnaissance, Nmap Scanning, Metasploit Framework, Web Application Security (OWASP Top 10), SQL Injection, XSS, CSRF, Privilege Escalation.
- **CY31xx**: Professional Elective I - 3 Credits (e.g., Cloud Security & Virtualization)

### Semester VI (CSE Cyber Security)
- **CY3003**: Digital Forensics & Incident Response (PCC) - 4 Credits (3-0-2)
  - Evidence Acquisition, Memory Forensics (Volatility), Disk Forensics (Autopsy, FTK), Timeline Analysis, Chain of Custody, Log Analysis, Incident Handling Workflows.
- **CY3004**: Secure Software Development & DevSecOps (PCC) - 3 Credits (3-0-0)
  - Static & Dynamic Code Analysis (SAST/DAST), Secure Coding Standards, Container Security (Docker/Kubernetes), CI/CD Security Pipelines.
- **CY3601**: Cyber Security Mini Project - 2 Credits

### Semester VII & VIII (CSE Cyber Security)
- **CY4001**: Cyber Laws, IPR & Governance - 3 Credits (IT Act, GDPR, HIPAA)
- **CY4701 / 4801**: Major Project & Dissertation - 12 Credits Total
- **CY4802**: Industry Internship / Security Operations Center (SOC) Training - 4 Credits
