# NITTE (NMAMIT & NMIT) B.Tech Course Syllabus & Details

## 1. Course Code: 25CSE201 - Data Structures (IPCC)
- **Teaching Department**: Computer Science & Engineering | **Credits**: 4 | **Type**: IPCC | **CIE+SEE**: 60+40 (or 50+50)
- **Module 1: Linear Structures & Stacks**: Data structure classification, arrays, dynamic memory allocation (`malloc`, `free`), pointers, structure pointers. Stacks: Array and structure representation, operations (push, pop, peek), infix to postfix conversion, postfix evaluation. Recursion: Factorial, Fibonacci, Tower of Hanoi. (Suggested Study Time: 8 hours)
- **Module 2: Queues & Linked Lists**: Queues: Ordinary queue, circular queue, priority queue. Linked Lists: Singly linked list, node insertion/deletion, linked stacks & queues, circular linked list, doubly linked list, circular doubly linked list. (Suggested Study Time: 8 hours)
- **Module 3: Non-Linear Structures - Trees & Graphs**: Trees: Binary trees, BST (Binary Search Tree), tree traversals (Preorder, Inorder, Postorder), threaded binary trees, expression trees. Graphs: Adjacency matrix, adjacency list representation, BFS, DFS. Hashing: Hash table, hash functions, collision resolution. (Suggested Study Time: 8 hours)

## 2. Course Code: IS3101-1 / CB3003-1 - Operating Systems Fundamentals (PCC)
- **Teaching Department**: Information Science / Cyber Security / CSE | **Credits**: 3/4 | **Type**: PCC
- **Module 1: Processes & CPU Scheduling**: OS structure, system calls, process concept, PCB, context switching, inter-process communication (IPC). Threads: Multithreading models. CPU Scheduling: FCFS, SJF, Round Robin, Priority scheduling. (Suggested Study Time: 6 hours)
- **Module 2: Process Synchronization & Deadlocks**: Race conditions, critical section problem, Peterson's solution, semaphores, monitors, Classic synchronization problems (Producer-Consumer, Readers-Writers). Deadlocks: Characterization, prevention, avoidance (Banker's Algorithm), detection and recovery. (Suggested Study Time: 6 hours)
- **Module 3: Memory & Storage Management**: Paging, page tables, segmentation, virtual memory, demand paging, page replacement algorithms (FIFO, LRU, Optimal). File Systems: Directory structure, allocation methods, free space management, disk scheduling algorithms (FCFS, SSTF, SCAN, C-SCAN). (Suggested Study Time: 6 hours)

## 3. Course Code: 25CSE211 / CS2101-1 - Computer Architecture and Organization (PCC)
- **Teaching Department**: Computer Science & Engineering | **Credits**: 3 | **Type**: PCC
- **Module 1: Basic Computer Organization & Arithmetic**: Functional units, operational concepts, bus structure, instruction execution, addressing modes. Arithmetic unit: Addition, subtraction, multiplication (signed operand, Booth's algorithm), integer division, IEEE 754 floating-point standard. (Suggested Study Time: 6 hours)
- **Module 2: Basic Processing Unit & Pipelining**: Complete instruction execution, hardwired control vs microprogrammed control. Pipelining: Pipeline hazards (structural, data, control), instruction-level parallelism, performance metrics. (Suggested Study Time: 6 hours)
- **Module 3: Memory System & I/O**: Semiconductor RAM/ROM memories, cache memory mapping functions (direct, associative, set-associative), FIFO & LRU replacement policies, virtual memory. I/O: Interrupts, DMA (Direct Memory Access), PCI bus, USB. (Suggested Study Time: 6 hours)

## 4. Course Code: 25MAT204 / MA1007-1 - Discrete Mathematical Structures
- **Teaching Department**: Mathematics | **Credits**: 3/4 | **Type**: BSC
- **Module 1: Mathematical Logic & Proofs**: Propositional logic, logical connectives, truth tables, rules of inference, predicate calculus, direct/indirect proofs, mathematical induction. (Suggested Study Time: 6 hours)
- **Module 2: Set Theory, Relations & Functions**: Relations, digraphs, equivalence relations, Warshall's algorithm for transitive closure. Functions: Permutations, injective/surjective functions. (Suggested Study Time: 6 hours)
- **Module 3: Graph Theory**: Basic terminology, Eulerian & Hamiltonian graphs, planar graphs, graph coloring, adjacency/incidence matrices, trees, minimum spanning trees (Kruskal's & Prim's algorithms), shortest path (Dijkstra's algorithm). (Suggested Study Time: 6 hours)

## 5. Course Code: IS2002-1 / CB2003-1 - Machine Learning Foundations (IPCC)
- **Teaching Department**: Information Science / Cyber Security | **Credits**: 4 | **Type**: IPCC
- **Module 1: Supervised Learning & Decision Trees**: Types of ML (Supervised, Unsupervised, Reinforcement). Decision trees: ID3 algorithm, entropy, information gain. Artificial Neural Networks: Perceptrons, backpropagation algorithm, multi-layer feedforward networks. (Suggested Study Time: 8 hours)
- **Module 2: Bayesian & Instance-Based Learning**: Bayes theorem, Naive Bayes classifier, k-Nearest Neighbors (k-NN), locally weighted regression, K-means clustering, EM algorithm. (Suggested Study Time: 8 hours)

## 6. Course Code: 26CSE102 / CS1005-2 - Introduction to Python Programming (PLC)
- **Teaching Department**: Computer Science & Engineering | **Credits**: 3 | **Type**: PLC
- **Module 1: Basics & Control Flow**: Python syntax, variables, data types, operators, conditional branching (`if`, `elif`, `else`), loops (`for`, `while`, `break`, `continue`). (Suggested Study Time: 5 hours)
- **Module 2: Functions, Data Structures & OOP**: Functions, default/named arguments, recursion, lambda functions. Data structures: Lists, tuples, sets, dictionaries, strings. OOP: Classes, objects, inheritance. File handling: Reading/writing CSV/text files. Exception handling, Pandas & Matplotlib. (Suggested Study Time: 6 hours)
